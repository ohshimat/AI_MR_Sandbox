# AI画像学習・生成GUI 利用手順

## 1. 起動

ポータブルリポジトリ直下の`start_image_learning_gui.cmd`をダブルクリックする。

初回だけ、同じ場所にある`setup_image_learning_gui.cmd`を先に実行する。GUI本体はポータブル側から動作し、Python、依存パッケージ、SDXL Base等の大容量実行資源だけをPC本体から参照する。

ブラウザで次のアドレスが開く。

```text
http://127.0.0.1:7860
```

このGUIはローカルPCだけで動作し、外部公開URLを作らない。

起動時にHugging Face Hub、Transformers、Datasetsのオフラインモードを有効化し、Gradioの分析送信を無効化する。初回セットアップとモデル取得の完了後は、ネットワークを切断した状態でも実験できる。

## 2. 最初に環境を確認

1. `環境・履歴`タブを開く。
2. `環境を再確認`を押す。
3. CUDAが利用可能であることを確認する。
4. GPU名、SDXL Base、Python、Accelerate、学習スクリプトを確認する。

学習前はLM Studio、Unity、D5、OllamaなどGPUを使用するアプリを終了する。

## 3. 1つまたは複数のLoRAから画像を生成

1. `画像生成`タブを開く。
2. `LoRA 1（必須）`で基本にするLoRAを選び、係数を指定する。
3. 単一LoRAで生成する場合は、`LoRA 2`と`LoRA 3`を空欄のままにする。
4. 複数LoRAで生成する場合は、`LoRA 2`・`LoRA 3`に追加LoRAを選び、個別の係数を指定する。
5. 画像生成プロンプトに、使用する各LoRAのトリガー語を入力する。
6. seedを `42` にする。
7. 横幅と縦幅を指定する。最初は `512 × 512`、全身の縦長画像は `512 × 768`を推奨する。
8. 画像生成フォルダを確認する。
9. `画像生成`を押す。

完了後、画面へ画像が表示され、指定フォルダへPNGと同名JSONが保存される。

`画像生成`を押すと、生成画像の上に回転表示と進行バーが表示される。この表示は生成の完了、失敗、または停止時に自動的に消える。待機表示中は、上部の状態表示とログで詳細を確認できる。

横幅と縦幅は8の倍数で指定する。解像度を上げるとGPUメモリ使用量が増えるため、8GB GPUでは段階的に試す。

複数LoRAはすべてSDXL Base用のものを使う。初回は2個だけを組み合わせ、例えば `0.7 + 0.6` 程度から試す。各係数の合計を1.0にする必要はないが、強すぎると顔、手足、装備が崩れる場合がある。同じLoRAを複数枠に入れることはできない。

```text
LoRA 1: 人物LoRA      係数 0.8
LoRA 2: スーツLoRA    係数 0.6
LoRA 3: 空欄LoRA        係数 0.4
```

生成後のJSONには、使用した全LoRAのパス、係数、SHA-256、内部アダプター名が保存される。

プレビューが更新されない場合は、古いGUIサーバーを`Ctrl+C`で終了し、リポジトリ直下の`start_image_learning_gui.cmd`から再起動する。生成画像本体は指定フォルダへ、ブラウザ表示用の複製はPC共通の一時領域へ保存される。

## 4. 学習画像を検査

1. `学習`タブを開く。
2. 学習画像フォルダを入力する。
3. `画像を検査`を押す。
4. `Valid: 20`、`Broken: 0`、`512px未満: 0`を確認する。

破損画像がある場合、学習は開始できない。

## 4.1 個別キャプションを作成

1. `詳細学習モード：個別キャプション編集`を開く。
2. `画像一覧とキャプションを読み込む`を押す。
3. サムネイルから画像を選択する。
4. 選択画像のキャプションを入力する。
5. `この画像のキャプションを保存`を押す。
6. 入力済み件数と未入力件数を確認する。

キャプションは画像と同じフォルダへUTF-8で保存される。

```text
image_001.png
image_001.txt
```

画像別キャプションを利用する場合は、`学習プロンプト方式`で`画像別キャプション（未入力は共通）`を選ぶ。同名`.txt`があり内容が入力されている画像には個別キャプションを使用し、それ以外の画像には共通／識別用学習プロンプトを適用する。したがって、すべての画像に`.txt`を作成する必要はない。

学習開始時、GUIは画像ごとに個別キャプションまたは共通プロンプトを確定し、Diffusers ImageFolder形式の`metadata.jsonl`を一時作成してDreamBooth LoRA学習へ渡す。元画像と元`.txt`は変更しない。一時作業フォルダは学習終了後に削除され、実際に使用した本文、適用元（個別／共通）、個別`.txt`のSHA-256が学習manifestへ記録される。

固定プロンプト方式も引き続き使用できる。この場合、GUIは画像だけを一時作業フォルダへ複製し、同名`.txt`を画像として誤読しない。

初回導入時は、リポジトリ直下の`setup_image_learning_gui.cmd`を一度実行する。依存パッケージはPC共通runtimeへ保存され、既存のPyTorch仮想環境は変更しない。

## 5. 最小回数での動作確認

1. 学習モードを `新規学習` にする。
2. `固定プロンプト`または`画像別キャプション（未入力は共通）`を選ぶ。
3. 既存データが入っていない専用の新規出力フォルダを指定する。
4. `1画像あたりの総学習回数`を `1` にする。
5. 画像数から計算された目標ステップを確認する。
6. 共通／識別用学習プロンプトを確認する。
7. `学習開始`を押す。

## 5.1 checkpointから継続する

1. `学習結果フォルダ`に継続対象の`checkpoint-N`が入っていることを確認する。
2. 学習モードを`checkpointから継続`にする。
3. `checkpointを確認`を押す。
4. `継続元checkpoint`の一覧から対象を選ぶ。初期選択は最新checkpointになる。
5. 今回追加したい量として、1画像あたりの総学習回数を設定する。
6. `学習開始`を押す。

継続時の最終目標ステップは、`選択checkpointのステップ＋今回の追加ステップ`で計算する。例えば`checkpoint-600`から390ステップ追加する場合、学習コマンドの最終目標は990になる。選択したcheckpoint名、追加ステップ、最終目標ステップはmanifestへ記録される。同じ出力フォルダに選択対象より新しいcheckpointが存在する場合は、後続データの上書きを防ぐため学習を開始しない。

学習結果フォルダには、LoRA、ログ、manifestが保存される。

## 6. 通常学習

動作確認が成功した後、別の空フォルダを指定し、`1画像あたりの総学習回数`を30などに設定して新規学習する。

目標ステップは次の式で自動計算され、学習開始時にも実際の画像数から再計算される。

```text
ceil(画像数 × 1画像あたりの総学習回数
     ÷ (batch size × gradient accumulation))
```

初期設定のbatch sizeとgradient accumulationはどちらも1なので、20枚を各30回学習する場合は600ステップになる。

初版の固定条件：

```text
resolution: 512
batch size: 1
learning rate: 1e-4
rank: 8
mixed precision: fp16
checkpoint: 100ステップごと
seed: 42
```

## 7. checkpointから継続

1. 学習モードを `checkpointから継続` にする。
2. `checkpoint-N`を含む学習結果フォルダを指定する。
3. `checkpointを確認`を押す。
4. 計算された目標ステップが、表示された最新checkpointより大きいことを確認する。
5. `学習開始`を押す。

単体のLoRA `.safetensors`だけから継続学習することはできない。optimizer等の状態を含むcheckpointが必要である。

## 8. 停止

学習または生成中に`実行中の処理を停止`を押す。停止まで少し時間がかかる場合がある。

停止済みcheckpointは削除しない。停止記録とログを確認してから、継続または新規実験を判断する。

## 9. 実験を外部ストレージへ保存

1. 学習または画像生成が終了していることを確認する。
2. `保存・復元`タブを開く。
3. 学習タブと画像生成タブの各フォルダが対象実験を示していることを確認する。
4. 外部ストレージの保存先ルートと実験名を入力する。
5. 継続学習が必要な場合だけ`checkpointも保存する`を有効にする。
6. `実験を外部ストレージへ保存`を押す。
7. 完全性が`正常`と表示されることを確認する。

保存先には次の構造が作成される。

```text
AI_MR_Research\experiments\experiment_001\
├─ dataset\
├─ training_output\
├─ generated\
├─ README.txt
└─ archive_manifest.json
```

`dataset`には学習画像と同名`.txt`を保存する。`training_output`はLoRA、manifest、ログ、必要に応じたcheckpointを保持する。`generated`には生成画像と生成条件JSONを保存する。

## 10. 実験をPCへ復元

1. 保存済み実験フォルダを入力する。
2. `保存データを検査`を押す。
3. SHA-256を含む完全性検査が正常であることを確認する。
4. PC側の復元先ルートを指定する。
5. `実験をPCへ復元`を押す。

復元先に同名フォルダが存在する場合は上書きしない。復元成功後、学習画像、学習結果、画像生成フォルダのGUI入力値が復元先へ更新される。

## 11. DreamBoothスクリプトの配置

DreamBooth SDXL学習スクリプトはGUIフォルダ内の`vendor\diffusers-0.41.0\examples\dreambooth`へ収録済みである。GUIは相対パスで参照するため、追加の移行操作は不要である。`環境・履歴`タブで学習スクリプトが存在すると表示されることを確認する。

## 12. 重要な注意

- `first_test`を新規学習の出力先にしない。
- 既存LoRAと同名の成果物がある場合、GUIは上書きを拒否する。
- 学習と画像生成は同時実行できない。
- 学習中にブラウザを閉じても子プロセスが直ちに停止するとは限らない。
- PCを終了する前にGUIの状態とGPUプロセスを確認する。
- 実在人物の画像は、本人の同意と研究倫理上の手続きを確認して使用する。

## 13. 終了

GUIを起動したコマンド画面で `Ctrl+C` を押す。ブラウザを閉じるだけではサーバーが残る場合がある。
