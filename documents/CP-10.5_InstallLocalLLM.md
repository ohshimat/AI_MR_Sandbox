# 6. Python-to-Ollama Connection

Sandbox側のPython処理から
Local LLMを利用できることを確認するため，
最小Python Scriptを作成した．

例：

```python
import json
import urllib.request

url = "http://localhost:11434/api/generate"

data = {
    "model": "qwen3:8b",
    "prompt": "こんにちは。短く答えてください。",
    "stream": False
}

request = urllib.request.Request(
    url,
    data=json.dumps(data).encode("utf-8"),
    headers={"Content-Type": "application/json"}
)

with urllib.request.urlopen(request) as response:
    result = json.loads(response.read().decode("utf-8"))

print(result["response"])
```

Python標準Libraryのみを使用し，
追加Python Packageを必要としない構成とした．

# 12. Responsibility Separation

CHECKPOINT-11でも，
LLMとSandbox Runtimeの責務を分離する．

```text
LLM
= 自然言語の意味解釈
  Action Requestの構造化

Permission
= 実行許可

AIR
= Human / AI / Environment間の
  空間的・意味的対応

Action
= Environmentへの作用

Verification
= Action結果の確認

Experience
= Interaction結果の記録
```

LLMにSandbox全体の判断を委ねない．

この分離により，
LLM Modelを変更しても
Sandbox Runtime側の基本Architectureを
維持できる構造とする．
